## 🇹🇼 必知補充：專屬台灣股市的「本土最強開源資料庫」（清單外隱藏神器）

雖然全球清單很豐富，但**最精準、完全免費且 100% 針對台股**的 API 其實是以下這些，本專案目前已全面導入：

1. **FinMind API（台灣開源財經庫・本專案核心）**
   * **特色**：收錄台股上市櫃每日開高低收、三大法人買賣超、融資融券、個股損益表、資產負債表、月營收。
   * **本專案應用**：在 [`modules/data_fetcher.py`](../modules/data_fetcher.py) 中作為開高低收 K 棒自動修補、季 EPS、獲利三率與月營收的核心支柱。
2. **臺灣證券交易所 OpenAPI (TWSE)**
   * **網址**：`https://openapi.twse.com.tw/`
   * **特色**：政府公開數據，提供每日三大法人買賣金額、盤後撮合統計、本益比/殖利率列表。
3. **證券櫃檯買賣中心 OpenAPI (TPEx)**
   * **網址**：`https://www.tpex.org.tw/web/stock/api/`
   * **特色**：提供上櫃股票與興櫃市場的官方即時與盤後數據。
4. **政府資料開放平台 (data.gov.tw)**
   * **特色**：提供「國發會景氣對策信號（紅黃藍景氣燈號）」、「中央銀行每日新台幣匯率結算」。
5. **Yahoo Finance (`yfinance` Python 庫)**
   * **特色**：完全免費、無需 API Key，支援台股代號加 `.TW` / `.TWO` 即時與歷史長天期日 K、週 K、月 K。
